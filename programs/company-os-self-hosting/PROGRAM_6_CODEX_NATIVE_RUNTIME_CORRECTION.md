# Program 6 Codex-native runtime correction

## Current reality decision

Program 6 previously assumed that Company OS needed an external API credential,
provider gateway, signed provider observations, and provider-derived telemetry
to become its execution fabric. That direction is retired. This development
session is hosted in Codex, and the Sol manager manually used native task tools
to create, wait on, read, list, and message separate tasks. The Company OS
controller does not yet invoke, admit, or durably observe those tools. The
intended runtime target is the host-operated task hierarchy itself.

The prior provider analysis and feature-off fixtures remain immutable historical
evidence for durability, receipt, cancellation-precedence, and parser failure
modes. They are not a launch plan and will not receive credentials, network
transport, controller activation, deployment, or scheduler work in Program 6.

## Intelligence decision

Optimize the native task contract around what the host truthfully exposes:

- native task/thread IDs and status;
- host-ID observations used only for coordination;
- requested model selection, separate from unavailable observed model identity;
- current status, ordered create/start events, optional terminal evidence, and
  elapsed duration when returned;
- terminal messages and inspectable artifacts.

Keep tokens, cost, cancellation acknowledgement, and observed model unavailable
unless the host explicitly exposes independently attributable fields. A message
asking a task to stop is cooperative intent, not a proven hard interrupt.

## Smallest useful correction

1. Add concise `manage-company-program` and `execute-bounded-task` global role
   skills to canonical source, with compact versioned charter/packet assets.
2. Route Company OS and the Luna fabric through those skills.
3. Add a host-only task-fabric playbook and deterministic exported-evidence
   validator; never claim repository code invokes app tools.
4. Record two tasks requested as `gpt-5.6-luna`, with observed model unavailable,
   plus five deterministic simulation scenarios.
5. Preserve scheduling, controller-native admission, installation, and external
   effects as blocked future gates.

## Acceptance boundary

The locally verified slice may be accepted as a reversible Company OS contract
and role-skill correction. Broader autonomous runtime operation remains NO-GO
because hard cancellation, installed fresh-thread role behavior, durable
controller-to-task admission, tokens, cost, and observed model identity are not
proven.
