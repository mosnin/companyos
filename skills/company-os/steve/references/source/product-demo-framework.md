# 1. Executive Summary

The Steve Jobs product demo philosophy is built around radical clarity, dramatic structure, and human meaning.

The product is not introduced as a bundle of features. It is revealed as a breakthrough that changes how people live, work, create, or communicate.

```yaml
jobs_demo_thesis:
  product_demo: theatrical_reveal_of_a_simple_human_transformation
  core_method: simplify_until_the_product_feels_inevitable
```

```yaml
essential_law:
  principle: A Jobs style demo makes the audience understand the product before they analyze it, desire it before they compare it, and remember it through one clear idea.
```

# 3. Jobs Style Sequence

```yaml
jobs_style_sequence:
  1_big_context:
    purpose: explain_why_this_moment_matters
  2_problem_or_old_category:
    purpose: show_limits_of_current_world
  3_tease_breakthrough:
    purpose: build anticipation
  4_name_the_product_or_category:
    purpose: give_audience_language
  5_repeat_core_claim:
    purpose: make_message_memorable
  6_show_product:
    purpose: make_claim_visible
  7_demo_key_interactions:
    purpose: prove_simplicity
  8_expand_benefits:
    purpose: show_life_change
  9_close_with_emotional_line:
    purpose: make_product_feel_historic_or_personal
```

# 6. Demo Design Rules

```yaml
jobs_demo_rules:
  - show_only_the_most_memorable_interactions
  - avoid_feature_overload
  - make_UI_or_product_feel_self_explanatory
  - use_clean_visuals
  - repeat_the_key_benefit
  - sequence_from_simple_to_surprising
  - make_the_hard_thing_look_easy
```

# 9. Failure Patterns

  too_many_features:
    fix: reduce_to_one_big_idea

    fix: translate_to_human_outcome

# 10. Jobs Style Reasoning Algorithm

```yaml
jobs_style_reasoning_algorithm:
  step_1_find_essence:
    question: What_is_the_one_thing_people_must_remember?
  step_2_define_old_way:
    question: What_current_experience_is_broken_or_limited?
  step_3_define_new_category:
    question: What_new_kind_of_product_or_behavior_are_we introducing?
  step_4_translate_to_human:
    question: What_does_this_change_in_daily_life?
  step_5_stage_reveal:
    question: When_does_the_audience_realize_this_is_different?
  step_6_demo_only_magic:
    question: What_interactions_make_the_value_obvious?
  step_7_repeat_phrase:
    question: What_words_should_echo_afterward?
```
