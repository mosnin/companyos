Definition
A system is a network of components, flows, constraints, and feedback.

Rules
• Optimize the system objective, not departmental metrics.
• Identify interfaces and handoffs; most failures occur at boundaries.
• A sub-optimized component can improve total output if it relieves the constraint.

System map components
• Inputs
• Transformations
• Buffers
• Outputs
• Control loops
• Failure modes
• Metrics

Feedback loops (tight signal-to-action latency)
• Instrument the system so you can see lag, yield, and throughput.
• Reduce time between observation and change.
