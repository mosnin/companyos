# Build Versus Integrate

When an existing implementation is supplied, replacement work is blocked until a bounded integration spike records:

1. exact repository, version, or commit;
2. required capability attempted;
3. install and execution commands;
4. runtime result;
5. blocking incompatibility;
6. why wrapping or extension cannot solve it;
7. estimated replacement cost;
8. receipt digest.

The controller treats an untested supplied implementation as the preferred critical-path action. Writing a replacement because it is easier for an agent is not admissible evidence.
