# Evaluator Economics

Evaluation follows the artifact.

1. Reuse a valid calibration receipt when evaluator bytes, benchmark bytes, artifact class, and required dimensions are unchanged.
2. Prefer existing negative, intermediate, and positive references.
3. Calibrate only the dimensions relevant to the current candidate.
4. Calibrate only the evaluator blocking current acceptance.
5. Use deterministic evaluators where model judgment is unnecessary.
6. Generate new calibration candidates only when no valid reference population exists.
7. Evaluator construction and calibration may consume at most 10 percent of remaining mission resources unless the governor explicitly authorizes a safety exception.

Before R3 use smoke tests and direct observation. At R3 add integration and basic independent review. At R4 add complete UX, security, reliability, performance, tenancy, and billing checks. R5 requires full independent reality acceptance.
