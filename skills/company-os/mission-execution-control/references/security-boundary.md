# Security Boundary

Security work is proportional to current consequence.

Before R3, protect credentials, tenant boundaries, unsafe input, destructive commands, and externally consequential actions while keeping local iteration fast.

After R3, expand adversarial testing around the actual product path. Before R4 and R5, require the complete security, privacy, authorization, billing, and reliability evidence appropriate to the objective.

Security review must attack the running artifact where possible. Reviewing a threat-model document alone does not prove the product is secure.
