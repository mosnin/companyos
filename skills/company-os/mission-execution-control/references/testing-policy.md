# Testing Policy

Tests must prove enforcement, not only serialization.

Required cases include:

1. research and documentation rejection without a consumer;
2. paused work class rejection;
3. First Reality subset derivation;
4. ordered evidence transitions;
5. deadline intervention and replacement;
6. stale and expired wake rejection;
7. supplied implementation replacement rejection;
8. exact scoped checkpointing;
9. director fabric binding to current mission and governor digests;
10. candidate assembly rejection when First Reality runtime observations are absent.
