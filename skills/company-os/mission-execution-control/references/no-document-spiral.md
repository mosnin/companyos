# No Document Spiral

After bootstrap, a document is admissible only when a currently executing task consumes it to resolve a named blocker or decision.

The controller rejects:

- general research without a consumer;
- architecture for deferred scope;
- benchmark expansion before one benchmark executes;
- evaluator design before a candidate exists;
- audits of reports presented as product progress;
- repeated status reports that contain no new artifact or runtime evidence.

When execution stalls, the corrective action is a product mutation, runtime command, integration attempt, or targeted repair, not another general report.
