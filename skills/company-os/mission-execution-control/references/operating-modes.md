# Enforced Operating Modes

## Normal

Discovery and execution may run together. A product lane starts immediately.

## Compression

Reality lags resource use. Documentation pauses. Research and governance require live consumer justification. Execution receives the majority of active capacity.

## Critical path

Only implementation, integration, runtime, repair, evaluation, packaging, and checkpoint work that directly advances the global bottleneck is admitted.

## Reality closure

No new features or broad research. Only integrate, run, fix, verify, package, and checkpoint.

## Accepted

No production work continues. Final checkpoint and concise documentation are allowed.

The controller, not the manager, enforces these modes.
