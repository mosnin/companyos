# Mission Classes

## Quick build

Thirty to ninety minutes. One manager, at most two workers, immediate reality spike, light discovery, basic independent review.

## Bounded feature

One to three hours. Small manager tree, First Reality Contract, targeted research, integration testing.

## Company mission

Three to seven hours. Full Executive Governor, dynamic organization, capability expansion, security and reliability closure.

## Long-running company

Persistent external scheduler, operational metrics, explicit renewal and cancellation authority.

The classifier considers objective breadth, number of user journeys, external dependencies, consequential effects, required artifact modalities, and expected integration count. The user may override the class.
