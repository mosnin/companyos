# Execution Failure Handling

A failed task is classified as environment, implementation, architecture, capability, authority, or external dependency failure.

The controller first assigns targeted repair to the dominant defect. It preserves independently passing dimensions. Repeating the same failed strategy without measurable bottleneck movement is prohibited.

Ordinary implementation uncertainty is researched or tested. Only genuine authority, irreversible effect, credential, budget, cancellation, or unavailable external dependency blockers are escalated to the operator.
