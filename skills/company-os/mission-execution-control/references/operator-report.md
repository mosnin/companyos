# Operator Report

The operator report contains only:

1. original objective;
2. mission class and remaining time;
3. current Reality Level;
4. connected user path that actually works;
5. missing user path;
6. global bottleneck;
7. governor mode;
8. execution, research, governance, and documentation ratios;
9. current artifact and runtime evidence;
10. checkpoints;
11. authority blockers requiring the operator;
12. next highest leverage execution action.

A long narrative does not count as mission progress.
