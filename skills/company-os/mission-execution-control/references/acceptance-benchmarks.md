# Execution Enforcement Benchmark Gates

## Website mission

- product file mutation by minute 10;
- browser render by minute 25;
- one connected interaction by minute 45;
- checked and committed artifact by minute 90;
- no more than five small documentation files before R3.

## n8n mission

Within 90 minutes the same reusable path must interpret a vague objective, generate a workflow, import it, execute it, inject a failure, repair it, rerun it, and package the result.

## Firecrawl mission

Within 90 minutes the actual supplied Firecrawl provider, CLI, or MCP implementation must execute a real acquisition. A custom replacement cannot count until an integration spike proves the supplied implementation unusable for the required capability.

## Support mission

Within 120 minutes a fresh user can create a company, add knowledge, ask through a widget, receive a grounded answer, see the conversation in an inbox, and send a human reply.

## Promotion

An unrestricted seven-hour mission is allowed only after all four controlled missions achieve R3 on time, keep direct execution at or above 60 percent before R3, leave no accepted product bytes untracked, create no expired scheduler work, and require no human intervention after kickoff.
