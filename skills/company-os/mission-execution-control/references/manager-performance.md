# Manager Performance and Replacement

Track per manager:

- time to first product mutation;
- time to first runnable artifact;
- time to connected behavior;
- execution ratio;
- research and documentation ratio;
- worker completion and rework rates;
- accepted artifact rate;
- integration delay;
- bottleneck movement;
- checkpoint latency;
- regressions introduced.

Failure signatures include repeated general research, document production without a consumer, missed execution deadlines, ignored governor pauses, uncommitted accepted bytes, agent fanout without bottleneck movement, repeated identical repair strategy, and progress reports without observable artifacts.

One missed deadline produces a precise intervention. A second miss replaces the worker. Two subordinate replacements, refusal to obey the governor, or failure to reallocate after an execution incident replaces the manager with a fresh context bound to the same durable mission evidence.
