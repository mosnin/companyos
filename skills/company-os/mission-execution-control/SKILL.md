# Mission Execution Control

Use this skill through the durable director. Managers do not invoke it as optional advice.

The controller owns one mission execution state containing:

- original objective and mission class;
- final capability map and First Reality capability subset;
- Reality Level derived from evidence;
- elapsed and remaining wall-clock budget;
- observable work allocation;
- execution deadlines and misses;
- current Executive Governor decision;
- scheduler lease and generation;
- manager and worker performance;
- checkpoint state;
- intervention and replacement orders.

## Enforcement

Before any discovery, research, architecture, implementation, integration, runtime, repair, evaluation, documentation, packaging, or checkpoint dispatch, the controller evaluates the mission and rejects work classes paused by the current governor decision.

Research and documentation after bootstrap require a consumer task, blocker ID, decision dependency, and bounded deadline. Supplied implementations must be exercised before replacement work is authorized.

Capability state advances only from exact artifact, runtime, browser, simulator, API, database, integration, or independent-evaluation evidence. Manager narrative cannot advance Reality Level.

## Deadlines

Default software deadlines are calculated from mission duration and include first mutation, first run, first rendered artifact, connected R3 behavior, independent runtime review, and reality closure. Misses trigger one corrective intervention, then worker replacement, then manager replacement.

## First Reality

Candidate one uses the First Reality Contract: one minimal connected user journey and only the artifact classes necessary to prove it. Final product capabilities remain mandatory for R4 and R5 but cannot block R3.

## Scheduler

Every wake is bound to mission ID, generation, not-before time, expiry, reason, expected state, and idempotency key. Expired or revoked generations cannot execute.

## Durability

Accepted product bytes must be checkpointed promptly. A lane cannot close while accepted product files remain outside the recorded checkpoint.
