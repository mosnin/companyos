# Define Outcome Artifacts

Company OS must model the thing being made in its native form.

A playable game is not a document. An audio experience is not a nonempty file. A service is
not source code existence. This skill compiles artifact classes into observation contracts that
state how the actual artifact can be exercised and what evidence must be captured.

Rich artifact classes require at least one modality specific observation. File existence,
nonempty text, hashes, and build success may be supporting evidence, but they are never sufficient
for an artifact whose value depends on behavior or experience.
