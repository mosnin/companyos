Checklist: Is this a real builder project
- Solves a fundamental bottleneck
- Creates or controls enabling infrastructure
- Has standardization potential
- Improves with scale or complements
- Can become a default layer for others
- Rewires behavior beyond a single product

Rubric: What type of builder is needed
If the issue is coordination, use state builder lens.
If the issue is transport, water, energy, or communication, use infrastructure lens.
If the issue is cost or throughput, use industrial lens.
If the issue is primitives or protocols, use platform lens.
If the issue is user lock in and complements, use ecosystem lens.
