# Company OS 0.6.0

## Product change

Company OS now treats a broad objective as the input to an outcome control plane rather than assuming the operator already supplied a complete implementation contract.

The control plane compiles measurable outcome claims, closes blocking unknowns with cited evidence, defines observable artifact classes, requires executable independent evaluators, binds benchmark tiers, calibrates evaluator discrimination, and requires reality acceptance from actual artifact evidence.

## Scale control

The pilot lane is limited to two managers, three workers per manager, and six total workers.

Larger elastic organizations require a content bound production scale authorization over the exact outcome contract, artifact contract, evaluator contract, benchmark contract, and calibration receipts. Contract drift invalidates the execution fabric.

## Completion control

Outcome controlled Luna fabric work cannot complete from a production team narrative. Completion requires exactly one accepted reality receipt bound to the original objective and included in the governed completion evidence.

## Portable verification

The existing Operator Command Center 0.5.1 acceptance is preserved as historical release evidence with its exact reviewed files, signed surface manifest, detached signature, reviewer public key, and reviewer fingerprint.

A local clone verifies that historical bundle without GitHub repository variables, secrets, environment configuration, or machine specific paths. The historical acceptance does not claim that the current 0.6.0 source revision was reviewed under the old 0.5.1 attestation.
